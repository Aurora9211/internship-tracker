# 实习投递追踪器

一个纯前端实习求职管理工具，帮助追踪投递进度、管理简历。

## 功能

- **投递追踪** — 记录公司、岗位、地点、行业、状态、投递日期、面试时间
- **智能匹配** — 输入公司名自动填充官网，粘贴官网自动识别公司名（内置 100+ 公司映射）
- **状态管理** — 待投递 → 已投递 → 等待回复 → 笔试 → 面试 → 已录用 / 已拒绝 / 已过期
- **测评追踪** — 记录在线测评完成状态和链接
- **JD 链接** — 保存岗位详情页链接，一键跳转
- **行业标签** — 14 个预设行业 + 自定义输入
- **数据本地化** — 所有数据存储在浏览器 localStorage，不上传服务器

## 技术栈

React 18 + Vite 6 + Tailwind CSS 4 + lucide-react

## 本地运行

```bash
npm install
npm run dev
```

## 部署

推送 `main` 分支后，GitHub Actions 自动部署到 GitHub Pages。

## 数据隐私

所有数据存储在浏览器本地 localStorage，不会上传到任何服务器。每个人只能看到自己浏览器中的数据。
